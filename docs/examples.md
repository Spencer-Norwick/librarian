# Synthetic first-run walkthrough

This demo uses invented text and a local JSON hook. It exercises ingest → enrich → maintain → short weekly without accounts, catalog lookup, or external delivery. The hook returns fixed demonstration content; it is not a real summarizer and must not be used for other readings.

Install and activate the CLI as described in the README. Then create a separate temporary workspace; keep the terminal's virtual environment active:

```bash
librarian_demo_dir=$(mktemp -d)
cd "$librarian_demo_dir"
printf 'Demo workspace: %s\n' "$librarian_demo_dir"
librarian mount --check
librarian init
librarian mount --privacy local --model none
librarian mount --privacy local --model none --apply

cat > inbox/Example_Ada_ReadingWithCare_2026_essay.txt <<'TEXT'
Reading With Care
By Ada Example
2026

A reading list is useful when it makes the next choice easier. Collecting more
texts does not create more time to read them. This synthetic essay recommends
choosing one short work, asking a concrete question before reading, and recording
one thought afterward. A plain local library can preserve every collected work
while a smaller weekly queue helps readers practice attention. The reader should
review suggested summaries and retain judgment about which work matters today.
TEXT

librarian ingest
librarian ingest --apply
librarian status
```

The preview shows a canonical destination; the applied ingest records the original filename in the index and ingest log. The entry still needs enrichment: no primer prompts were generated by ingest.

Create the synthetic local hook:

```bash
cat > _state/demo-enrich.py <<'PY'
import json
import sys

payload = json.load(sys.stdin)
assert payload["work"]["title"] == "Reading With Care", "Demo hook only supports the synthetic essay"
print(json.dumps({
    "summary": "This synthetic essay argues that a smaller weekly reading queue helps readers practice attention while a plain local library preserves the complete collection.",
    "primer_prompts": [
        "What makes the next reading choice easier?",
        "How does a weekly queue differ from a complete collection?",
        "What judgment should the reader retain?"
    ],
    "tags": ["reading", "attention"],
    "related": "None."
}))
PY

librarian mount --privacy assisted --model custom --model-command "python3 _state/demo-enrich.py"
librarian mount --privacy assisted --model custom --model-command "python3 _state/demo-enrich.py" --apply
librarian enrich "Reading With Care"
librarian enrich "Reading With Care" --apply
librarian maintain
librarian maintain --apply
librarian lint

librarian mount --weekly-mode short --weekly-max-minutes 0
librarian mount --weekly-mode short --weekly-max-minutes 0 --apply
librarian weekly
librarian weekly --apply
librarian status
```

Review each preview before its applied counterpart. `maintain` may report that no repair is needed. Lint should pass, the weekly preview should select the synthetic essay, and the applied weekly should write a Markdown draft under `_output/weekly-read-drafts/` and mark it sent. No delivery flags are used, so no desktop notification, Messages, or email is sent. The temporary workspace remains at the printed path; this demo does not delete it.

For real readings, replace the demo hook with a reviewed provider-specific hook described in [mount.md](mount.md), or write reviewed summary and prompt fields manually. External enrichment runs even during dry-run; explicit invocation is approval to execute that configured hook.

## Small command examples

Correct a work's identity and preview its new filename:

```bash
librarian edit "Reading With Care" --title "Reading With Care" --author "Example, Ada" --year 2026 --type essay
```

For local delivery on macOS, configure a Messages recipient first, then explicitly request the desired channels:

```bash
librarian weekly-due --apply --notify-mac --open --message-self
```

Email is separately configured and explicitly requested with `librarian weekly --email --apply`. `librarian resend-latest --apply` explicitly resends the previous digest to Messages; it does not choose a new filtered work.
